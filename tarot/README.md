# 每日一牌 · Tarot Journal

一个本地使用的每日塔罗学习日记。双击 `index.html` 用浏览器打开即可，不需要联网或安装。

## 使用流程
1. **上午抽牌**：在月历"今天"的格子里直接输入牌名（`temp` → 节制，`星` → 星星 / 星币一…星币国王，`星币3`、`3 of cups`、`侍从` 都可以），回车或点选。
2. 自动进入当天记录：选择正位 / 逆位，填写**牌面观察**和**初步感受**（先别查牌义）。
3. **晚上回顾**：点开当天格子，写下今天对应这张牌的事情。
4. 在"被印证的关键词"中点选应验的关键词（虚线框是根据你写的内容自动匹配到的建议），也可以添加自己的关键词。这些关键词会显示在月历牌面下方。
5. 点"打开牌面解读"，对照牌面元素、正逆位释义和自省问题学习。

"牌库"页可以浏览全部 78 张牌，并显示每张牌你抽到过几次、是哪几天。

## 数据保存
- 记录自动保存在浏览器的 localStorage 中（同一浏览器、同一文件路径下持续保留）。
- **请定期点击"导出备份"**，生成 JSON 文件；换电脑/换浏览器时用"导入备份"恢复。清除浏览器数据会删掉 localStorage。

## 资料来源
- 牌面图片：Rider-Waite-Smith 塔罗（Pamela Colman Smith 绘，1909，公有领域），取自 npm 包 `@cometpisces/tarot-kit-images`。
- 释义：综合 A. E. Waite《The Pictorial Key to the Tarot》、黄金黎明元素/占星对应，以及 Biddy Tarot、Labyrinthos 等常见学习资料的通行解读，见 `cards-data.js`，可自行修改补充。
